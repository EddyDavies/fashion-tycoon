## 1. The Pantone FHI System

### 1.1 What the FHI System Is

Pantone maintains two distinct colour systems. The **Pantone Matching System (PMS)** was built for print and graphic design — it describes colour using ink formulas on paper. The **Fashion, Home + Interiors (FHI) system** was built for soft goods — it describes colour using dye recipes applied to textile substrates.

The FHI system is the standard for all apparel and textile production. It contains **2,845 colours** (as of 2026), each physically realised as a fabric swatch dyed on 100% cotton. These swatches are the legal reference: when a brand specifies "19-4052 TCX," every factory, dye house, and mill in the world is pointing at the same physical colour standard.

Think of FHI as a global coordinate system for colour. A designer in London and a dye house in Guangzhou can both hold the same Pantone swatch and know with certainty they are working from the same reference — no monitor, no screen, no language barrier involved.

### 1.2 The FHI Numbering System

Every FHI colour has a **six-digit number** that encodes its position in colour space:

- **First two digits** — Lightness value (11 = near-white, 19 = near-black)
- **Middle two digits** — Hue (the colour family: yellow, red, blue, green, etc.)
- **Last two digits** — Chroma level (how saturated or muted the colour is)

Example: `19-4052 TCX` — a deep (19), blue-family (40), moderately saturated (52) colour — Classic Blue, Pantone's 2020 Colour of the Year.

The suffix indicates the substrate:
- **TCX** (Textile Cotton eXtended) — colour is dyed on 100% cotton; the primary reference for apparel
- **TPG** (Textile Paper Guide) — colour on paper; used for hard goods, accessories, packaging, and situations where the cotton swatch is not available

### 1.3 How FHI Differs from PMS

| Dimension | Pantone Matching System (PMS) | Pantone FHI System |
|---|---|---|
| Primary use | Print, packaging, branding | Apparel, textiles, soft home goods |
| Reference substrate | Coated or uncoated paper | Cotton fabric (TCX) or paper (TPG) |
| Colour rendering | Ink formulas | Dye recipes |
| Colour codes | e.g., PMS 286 C | e.g., 19-4150 TCX |
| Palette priorities | Saturated shelf-pop colours | Neutrals, naturals, wider soft-goods range |
| Number of colours | ~1,867 (Solid Chips) | ~2,845 (FHI) |

**A PMS code cannot be used as a textile specification.** Ink on paper behaves nothing like dye on fabric. Using a PMS reference in a tech pack sent to a fabric mill is a common beginner mistake that causes expensive colour miscommunication.

### 1.4 Why Factories Need Pantone References

Without a physical colour standard, colour communication collapses into subjective language: "a warm sand," "a dusty blue," "something like terracotta." Every party in the supply chain interprets those words differently, and screens compound the problem — the same hex value looks different on every monitor, in different ambient light, and across different material surfaces.

A Pantone TCX code transforms colour from a subjective opinion into a **measurable, enforceable manufacturing standard**. It enables:

- **Dye house formulation**: The mill can look up or derive the correct dye recipe for that exact colour target.
- **Lab dip alignment**: All parties judge the lab dip against the same physical swatch, not against memory or a screen.
- **Quality control**: Bulk fabric can be measured against the approved standard with a spectrophotometer, giving a Delta E (colour difference) number.
- **Rejection authority**: If bulk fabric exceeds the agreed Delta E tolerance, the buyer has clear grounds to reject without dispute.

Re-dyeing rejected bulk fabric can consume over 30% of the total production budget and delay launches by weeks. Precise Pantone specification upfront is the primary prevention mechanism.

At the Canton Fair and other large sourcing events, export-oriented Chinese manufacturers are fluent in Pantone references. Specifying a TCX code is a professional credibility marker — it signals that a brand founder understands supply chain communication and can be worked with efficiently.

### 1.5 How Brand Founders Specify Colour to Manufacturers

The colour specification lives in the **tech pack** (technical package). The colour page of a tech pack should include:

1. **Pantone TCX code** — the primary binding reference (e.g., `15-1062 TCX`)
2. **Pantone colour name** — for human readability (e.g., `Flame Orange`)
3. **Hex value** — for digital design and e-commerce use only, never as a manufacturing spec
4. **A visual swatch** — a small colour block for quick visual reference
5. **Colour-to-component mapping** — which Pantone applies to which part of the garment (shell, lining, trim, label, stitching)

For brands without access to physical Pantone guides (which cost $300–$1,200), specifying the TCX code and pairing it with a printed swatch from a calibrated colour-matched output is an acceptable starting point, though the physical guide remains the gold standard.

Physical Pantone guides should be **replaced every 12–18 months** as the fabric swatches fade from light and humidity, causing colour drift that can lead to disagreements with factories using newer editions.

## 2. Seasonal Colour Palettes

### 2.1 How Fashion Operates on Seasonal Logic

The fashion industry runs on a two-season calendar:

- **Spring/Summer (S/S)** — collections presented January–February for retail delivery March–July
- **Autumn/Winter (A/W)** — collections presented June–September for retail delivery August–January

Because of the lead times involved in manufacturing — typically 90–180 days from design sign-off to factory shipment — brands are designing **at least six months ahead** of when a product hits the market. For brands sourcing from China (Canton Fair runs April and October), this timeline is non-negotiable.

Seasonal palette logic serves two purposes:

1. **Merchandising coherence** — colours within a seasonal collection should work together on the rail, in a lookbook, and in a capsule wardrobe. A customer buying multiple pieces should be able to mix them.
2. **Trend relevance** — seasonal palettes position the brand within the current cultural and aesthetic moment, signalling that the brand is alive and engaged with its customer.

### 2.2 The Role of Trend Forecasters

**WGSN** (World Global Style Network) is the dominant professional trend forecasting service. It publishes seasonal colour forecasts up to five seasons ahead, with proprietary AI tools (TrendCurve, Colour Vision) that track runway data, social signals, and retail sell-through to achieve approximately 94% accuracy on 12-month-ahead forecasts. WGSN collaborates with **Coloro** — a colour system that integrates with Pantone and provides a five-digit colour code system — to publish Key Colours for each season.

Key WGSN/Coloro seasonal highlights:
- **A/W 25/26 Key Colours**: Celestial Yellow, Cherry Lacquer, Retro Blue, Neon Flare, Future Dusk
- **A/W 26/27 direction**: Cocoa Powder (warm earth), Wax Paper (soft neutral), Fresh Purple, Green Glow, Transformative Teal
- **2028 Colour of the Year**: Radiant Earth (warm assertive orange)

**Pantone Color of the Year** is the most widely publicised colour forecast. It has been published annually since 2000 and is selected by the Pantone Color Institute based on cultural signals across art, film, design, social media, and consumer sentiment. It functions as a cultural compass more than a prescriptive production directive.
- **2025**: Future Dusk (blue-purple)
- **2026**: Cloud Dancer (luminous off-white — the first white in the programme's history)

**Trendalytics** offers AI-powered trend forecasting with predictive data tools, covering the Pantone Color of the Year's downstream effects on fashion, beauty, and home retail.

**Other trend sources** include: runway coverage from Vogue Runway and Fashion Snoops; trend reports at trade fairs (Première Vision in Paris, Texworld); and retail analytics platforms that track what is actually selling by colour.

### 2.3 How a Small Brand Decides Their Seasonal Palette

For an independent brand without a WGSN subscription, a workable process is:

**Step 1: Anchor to a core palette**
Define 2–4 colours that are permanent to the brand — these appear in every season and form the recognisable DNA. Typically one or two neutrals plus one signature colour.

**Step 2: Layer seasonal accent colours**
Each season, add 2–3 trend-adjacent accent colours that feel current but align with the brand's identity. These can rotate out each season.

**Step 3: Cross-reference trend signals**
Free sources: Pantone's seasonal fashion colour trend reports (published publicly each NYFW season); Vogue Runway's colour analysis; Pinterest trend reports; and Instagram's Creative Trends report. These identify broad directional shifts without requiring expensive subscriptions.

**Step 4: Validate against fabric availability**
Before committing to a palette, check with your target mills that the relevant Pantone codes are achievable in your fabric and within your MOQ. Some colours — particularly very bright neons or highly specific neutrals — require custom dye lots that carry high minimums.

**Step 5: Map each colour to a Pantone TCX code**
Before any tech pack is produced, every colour in the seasonal palette needs a TCX code assigned. This is the moment where the palette stops being mood board and starts being manufacturable.

## 3. Colour Palette Archetypes for Brand Identity

These archetypes describe the repeating patterns in fashion brand colour strategy. Most brands occupy one primary archetype with seasonal variations within it.

### 3.1 Neutral / Minimal

**Core colours**: Chalk white, warm cream, cool grey, light taupe, mid-grey, black, natural ecru.

**Pantone references (examples)**: 11-0601 TCX (Bright White), 12-0104 TCX (Whitecap Gray), 16-1107 TCX (Fog), 19-3911 TCX (Jet Black).

**Brand logic**: Palette is built almost entirely from neutrals, with texture, silhouette, and material doing the aesthetic work instead of colour. Appeals to customers who want wardrobe versatility and a "no decisions" dressing approach. Strong in minimalist DTC brands, genderless labels, and high-end basics.

**Pitfall**: Visually weak on social media and e-commerce if not supported by strong photography.

### 3.2 Earth Tones

**Core colours**: Terracotta, ochre, burnt orange, rust, warm camel, olive, moss green, tobacco brown, clay.

**Pantone references (examples)**: 17-1340 TCX (Sandstorm), 18-1244 TCX (Copper Tan), 18-1048 TCX (Sunburn), 17-0535 TCX (Fern), 18-1048 TCX (Adobe).

**Brand logic**: Palette draws from the natural world — soil, bark, stone, dried botanicals. Signals craft, sustainability, and warmth. Sits comfortably alongside linen, cotton, and natural-fibre narratives. Strong in slow fashion, artisan, and outdoor-adjacent brands.

**Seasonal behaviour**: Earth tones are strongest in A/W. In S/S, the palette lightens and desaturates — towards pale ochres, dusty terracottas, sage rather than deep moss.

### 3.3 Bright / Saturated

**Core colours**: Primary red, cobalt blue, sunshine yellow, electric green, hot pink, orange; or neon/acid variants (neon yellow, acid green, UV pink).

**Pantone references (examples)**: 18-1664 TCX (Fiesta), 19-4241 TCX (Strong Blue), 13-0858 TCX (Vibrant Yellow), 17-0145 TCX (Jasmine Green).

**Brand logic**: Colour is the product. Brand relies on colour impact as the primary differentiator. Strong in sportswear, kidswear, Gen Z-targeted brands, and streetwear. Maximalist energy; colour is meant to be seen.

**Manufacturing note**: Bright saturated colours — particularly neons — are among the hardest to achieve with consistent colour fastness. Fluorescent dyes are inherently less stable to light than standard reactive dyes. Require explicit colour fastness specifications in tech packs.

### 3.4 Pastels / Soft Tones

**Core colours**: Baby pink, powder blue, lavender, mint, blush, butter yellow, peach, soft sage.

**Pantone references (examples)**: 14-2311 TCX (Cherry Blossom), 15-3817 TCX (Placid Blue), 15-3508 TCX (Orchid Haze), 12-0712 TCX (Vanilla Custard).

**Brand logic**: Softness, romanticism, femininity, approachability. Strong in womenswear, occasionwear, bridesmaid categories, and brands targeting a broadly aspirational aesthetic. Very strong in S/S collections.

**Seasonal behaviour**: Pastels are the archetypal S/S palette. In A/W they become dustier and greyer — "muted pastels" or "smoked pastels" rather than the clean, clear tones of summer.

### 3.5 Quiet Luxury / Muted

**Core colours**: Stone, greige, warm ivory, dusty blush, dusty sage, slate blue, mushroom, off-white, camel.

**Pantone references (examples)**: 13-0002 TCX (Blanc de Blanc), 16-1318 TCX (Warm Taupe), 16-1510 TCX (Peach Beige), 17-4015 TCX (Silver Blue).

**Brand logic**: The defining aesthetic of the mid-2020s luxury market. Colours are not neutral but are not saturated — they sit in the muted, slightly greyed middle ground. Nothing shouts. The palette communicates wealth through restraint. Often described by adjectives like "considered," "understated," "timeless." Directly associated with brands like The Row, Loro Piana, and Toteme.

**Technical note**: Muted tones require precision in the dye bath. The small margin between "right" and "too grey" or "too beige" is narrower than for saturated colours. Lab dips require careful assessment.

### 3.6 Monochromatic vs. Complementary vs. Analogous

These describe the **structural relationship** between colours in a palette, regardless of which archetype a brand occupies:

**Monochromatic**: One hue, varied in lightness and saturation. Example: a collection in shades from pale blush to deep burgundy — all red-family. Creates strong brand coherence; easy to merchandise; can feel limited if overdone.

**Analogous**: Colours adjacent on the colour wheel. Example: terracotta + olive + mustard (all in the warm orange-yellow-green segment). Feels harmonious and natural; low visual tension; well-suited to earth tone and quiet luxury palettes.

**Complementary**: Colours opposite on the colour wheel. Example: cobalt blue + burnt orange; forest green + terracotta. Creates visual tension and energy. More complex to execute well; strong in maximalist and editorial brands.

**Split complementary / Triadic**: More complex combinations using three or more hue families. Generally avoided in small-brand palette strategy as it increases the risk of visual incoherence.

### 3.7 Dark / Moody

**Core colours**: Midnight navy, deep burgundy, forest green, charcoal, black, oxblood, aubergine, deep teal.

**Pantone references (examples)**: 19-4024 TCX (Navy Peony), 19-1934 TCX (Burgundy), 19-0315 TCX (Kombu Green), 18-0306 TCX (Charcoal).

**Brand logic**: Drama, authority, and sophistication. The natural A/W archetype. Strong in tailoring-forward brands, eveningwear, menswear, and any brand positioning around confidence and power. Dark palettes are highly forgiving in production — depth of shade masks minor dye lot variation that would be visible in lighter colours.

### 3.8 Coastal / Resort

**Core colours**: Aqua, turquoise, coral, sun yellow, sandy beige, bright white, sea glass green, faded denim blue.

**Pantone references (examples)**: 14-4522 TCX (Crystal Blue), 16-1546 TCX (Coral), 12-0722 TCX (Vanilla Cream), 16-4132 TCX (Cerulean).

**Brand logic**: Vacation energy. Optimistic, warm, and escapist. Strong in resort wear, holiday capsules, swimwear-adjacent categories, and brands serving a warm-climate or travel-oriented customer. Typically S/S but can anchor a dedicated resort or cruise drop.

**Manufacturing note**: Coral and turquoise tones present colour fastness challenges — particularly fastness to chlorine (pool water) and perspiration. Any brand in swimwear or resort must explicitly test for ISO 105-E03 (colour fastness to chlorinated water) and ISO 105-E04 (perspiration).

## 4. Colour and Fabric/Material

### 4.1 Why the Same Pantone Code Looks Different on Different Fabrics

A Pantone TCX swatch is dyed on 100% combed cotton. When a factory attempts to match that swatch on a different fabric — polyester, silk, linen, a cotton-poly blend — the result will always differ. This is because:

1. **Fibre chemistry**: Different fibres have different chemical structures. Dye molecules bond differently to cellulose (cotton, linen), protein (wool, silk), and synthetic (polyester, nylon) fibres. The same dye formula produces different colour results on each.
2. **Surface texture**: A smooth, tightly woven satin reflects more light, making colour appear lighter and more saturated. A loose weave or brushed surface scatters light, making colour appear slightly dulled or shifted.
3. **Fibre optical properties**: Silk naturally adds luminosity; polyester can add a synthetic brightness; linen absorbs differently from cotton even though both are cellulose.
4. **Dye class limitation**: Some dye classes simply cannot achieve the same colour gamut on all fibres. A vivid coral achievable on cotton with reactive dyes may only be approximated on polyester with disperse dyes.

**Practical implication**: When a brand uses multiple fabric types in a collection, achieving colour continuity across them requires separate colour matching exercises for each substrate, not a single lab dip.

### 4.2 Dyeing Methods by Fibre Type

#### Reactive Dyes — Cotton, Linen, Viscose, Wool, Silk

The dominant dye class for cellulosic fibres (cotton, linen, viscose) and widely used on wool and silk. Reactive dye molecules form a **covalent chemical bond** with the fibre — they become part of the fibre rather than sitting on the surface. This produces:
- Excellent colour fastness to washing
- Excellent colour fastness to light
- Full colour range including deep saturates and clean pastels
- Highest colour accuracy relative to Pantone TCX references (since TCX swatches are dyed on cotton with reactive dyes)

**Process**: Fabric is pre-treated with sodium carbonate (to swell fibres), immersed in the dye bath, chemically fixed, then thoroughly washed off. Three temperature classes exist — cold brand (room temperature), hot brand (60–80°C), and high-temperature (100°C+).

**Best for**: T-shirts, knitwear, shirting, denim (non-indigo), jersey, woven cottons, linen garments, viscose dresses.

#### Vat Dyes — Cotton, Denim, High-Durability Applications

Vat dyes are insoluble in water in their natural state. They must be chemically reduced to a soluble form to enter the fibre, then oxidised back to their insoluble form once inside — trapping the colour within the fibre structure. This produces:
- Exceptional colour fastness — the highest of any dye class
- Excellent light fastness and wash fastness
- A slightly narrower colour range (historically, blues and greens dominate)

Indigo — the dye of denim — is the most famous vat dye. The characteristic fading of denim over time (ring dyeing) is a deliberate result of partial vat dye penetration.

**Best for**: Workwear, denim, uniforms, childrenswear requiring repeated washing, high-durability applications.

#### Acid Dyes — Wool, Silk, Nylon

Acid dyes are water-soluble anionic dyes applied in an acidic bath (pH 2–6). They bond to **protein fibres** (wool, silk) and to nylon, producing vibrant, brilliant colours with good light fastness and excellent shade range. They cannot dye cotton.

The name "acid dye" refers to the acidic dyeing conditions, not the nature of the dye itself.

**Process**: Fabric is immersed in a heated dye bath with acetic acid or ammonium sulphate; temperature is controlled carefully to avoid damaging delicate silk fibres.

**Best for**: Silk blouses, wool knitwear, cashmere, nylon linings and trims, luxury suiting.

#### Disperse Dyes — Polyester, Nylon, Acetate, Spandex/Elastane

Polyester is hydrophobic — it repels water and cannot absorb standard water-based dyes. Disperse dyes are fine-particle, water-insoluble dyes that penetrate the polyester fibre structure under **high temperature (130°C) and pressure** in an autoclave. At these temperatures, polyester's molecular chains temporarily loosen, allowing dye molecules to migrate in; on cooling, they are trapped.

**Characteristics**:
- Good to excellent colour fastness on polyester
- Narrower colour gamut than reactive dyes — very saturated brights are harder to achieve
- Cannot be used on cotton without auxiliary chemicals
- Require sublimation printing for some applications

**Polyester and light colours**: Pale, bright pastels on polyester are notoriously difficult to achieve with colour accuracy. The fibre's inherent brightness can cause a slight optical interference with pale shades.

**Best for**: Sportswear, activewear, swimwear, shell fabrics in outdoor gear, linings, technical textiles.

#### Blended Fabrics (e.g., Cotton-Polyester, Cotton-Linen)

Blended fabrics require either a **two-step dyeing process** (reactive dye for cotton + disperse dye for polyester, at different temperatures) or careful selection of dye combinations that can treat both fibres in one bath. This complexity:
- Increases dyeing cost
- Increases risk of cross-staining (where dye intended for one fibre partially affects the other)
- Often results in a "heathered" effect where each fibre takes up slightly different colour intensity
- Requires explicit specification in the tech pack — simply writing a TCX code is insufficient; the fabric composition must also be stated

### 4.3 Colour Fastness: What It Means and Why It Matters

Colour fastness is the resistance of a dyed fabric to losing or transferring colour during its use lifecycle. It is the quality measure that determines whether a garment still looks the same after 30 washes, whether a navy dye crocks (rubs off) onto a white sofa, or whether a swimsuit fades after a season at the pool.

**The rating scale** runs from 1 to 5:
- **5** = no colour change or staining (excellent)
- **4** = slight change (good, acceptable for most applications)
- **3** = moderate change (marginal; only acceptable for low-wash items)
- **1–2** = significant change (unacceptable for commercial apparel)

Most brands should specify **minimum Grade 4** for colour change and colour staining in their tech pack.

**Key test standards** (brands must specify one system — AATCC for North America/US buyers, ISO for Europe/international):

| Test | AATCC Standard | ISO Equivalent | What It Measures |
|---|---|---|---|
| Wash fastness | AATCC 61 | ISO 105-C06 | Fading and dye bleeding during laundering |
| Light fastness | AATCC 16.3 | ISO 105-B02 | Fading under UV/sunlight exposure |
| Crocking (rubbing) | AATCC 8 | ISO 105-X12 | Dye transfer through dry and wet rubbing |
| Water | AATCC 107 | ISO 105-E01 | Bleeding when wet (rain, sweat) |
| Perspiration | AATCC 15 | ISO 105-E04 | Colour change from body sweat (acid + alkaline) |
| Chlorinated water | — | ISO 105-E03 | Critical for swimwear; pool chlorine degrades many dyes |

**Why colour fastness matters for Canton Fair sourcing specifically**: Chinese export factories are accustomed to buyer-specified fastness requirements. If no standard is specified in the tech pack, the factory will dye to their own internal standard, which may or may not match what the brand's end customers expect. Always include fastness requirements in the tech pack.

### 4.4 Colour Behaviour by Fabric Type: Summary

| Fabric | Dye Class | Colour Gamut | Relative Brightness | Wash Fastness | Notes |
|---|---|---|---|---|---|
| Cotton | Reactive | Full | Natural, clear | Excellent | Most accurate Pantone TCX match |
| Linen | Reactive | Full | Slightly muted, natural | Good | Uneven uptake possible; texture adds depth |
| Viscose / Rayon | Reactive | Full | Bright, lustrous | Good | Absorbs deeply; bleeds more readily |
| Silk | Acid | Full | High lustre, luminous | Good | Delicate process; heat sensitive |
| Wool | Reactive / Acid | Full | Warm, slightly soft | Good | Can felt if temperature not controlled |
| Polyester | Disperse | Good (slightly narrower) | Can be bright but synthetic | Very good | Deep saturates more difficult; pale brights tricky |
| Nylon | Acid / Disperse | Good | Neutral | Good | Better dye uptake than polyester |
| Cotton-Poly blend | Reactive + Disperse | Good | Mixed — heather effect possible | Good | Two-step process; cost increase |

## 5. Colour Specification Workflow: Design to Factory

### 5.1 Overview of the Process

```
Brand selects colour → Assigns Pantone TCX code → Includes in tech pack →
Factory receives tech pack → Dye house develops lab dip → Brand approves lab dip →
Factory dyes bulk → QC checks bulk against approved lab dip → Brand receives goods
```

Each stage is a checkpoint. If colour approval is rushed or skipped at any stage, errors compound through to the finished goods.

### 5.2 Lab Dip: The First Physical Test

A **lab dip** is a small sample of the production fabric dyed to the target colour. It is the factory's first attempt to match the Pantone reference on the actual substrate being used for production.

**Why lab dips exist**: The Pantone TCX swatch is dyed on standard cotton. The production fabric may be a different cotton construction, a different weight, or a different fibre entirely. The lab dip translates the abstract Pantone target into a recipe that works for the actual production material.

**Process**:
1. The factory dye house receives the tech pack with the TCX code and the fabric specification.
2. The dye house formulates 2–4 dye recipes that they believe will achieve the target.
3. Small fabric samples (typically A4-sized or smaller) are dyed using each recipe.
4. The factory reviews internally under standardised lighting, selects the closest options, and ships 2–4 lab dip options to the brand.
5. The brand evaluates lab dips against the physical Pantone swatch under standardised lighting.
6. The brand selects the closest and communicates corrections (e.g., "add more red," "lighten 10%," "too grey").
7. The factory redips until an option is approved.

**Critical rules**:
- Lab dips must be made on the **exact production fabric** — not a substitute. Different weights, yarn densities, and constructions absorb dye differently.
- Never approve a lab dip purely on screen. Photograph the dip for records, but evaluate it physically.
- Expect 2–3 rounds of lab dip submission before approval. Complex colours (especially muted tones, dusty pastels, and custom neutrals) often require more.
- Most brands accept a **Delta E (ΔE) of 1.0–2.0** for shell fabrics. Delta E is a numerical measure of colour difference — a ΔE of 1.0 is barely perceptible to the human eye; ΔE of 2.0 is noticeable under close inspection but acceptable in production.

### 5.3 Strike-Off: Print Colour Approval

A **strike-off** is the equivalent of a lab dip for printed fabrics — a sample of the print design executed on the actual production fabric using actual production machinery and inks.

Strike-offs confirm:
- Print colour accuracy (how each colour in the print design reads on the fabric)
- Print registration (alignment of repeat patterns)
- Scale and proportion of the print at actual size
- Ink penetration and hand-feel

Strike-offs go through the same approval cycle as lab dips: factory produces options, brand reviews against the original artwork and Pantone references, corrections are communicated, and the process repeats until approval.

**Lab dip vs. strike-off**: Lab dips are for solid-dye fabrics; strike-offs are for printed fabrics. A garment with both a dyed ground colour and a printed pattern may require both.

### 5.4 Metamerism: The Problem of Changing Light

**Metamerism** is the phenomenon where two colours that appear to match under one light source look different under another. A lab dip that is approved in the factory's fluorescent workroom may look slightly mismatched in the daylight of the brand's studio, and significantly mismatched under the incandescent lighting of a boutique.

This happens because two different dye formulas can produce surfaces that reflect similar amounts of light in one part of the spectrum (making them match under one light) but different amounts in another (causing a mismatch under different light). These are called **metameric pairs**.

**Standard light sources** used for colour evaluation:
- **D65** — standard daylight (6500K); the primary standard for textile colour approval
- **TL84** — shop / retail fluorescent lighting; simulates department store viewing conditions
- **A** — incandescent / warm artificial light; simulates home or boutique lighting
- **UV** — reveals optical brighteners in fabrics

**How to check for metamerism**: Evaluate lab dips under at least two light sources — D65 and TL84. If the dip matches under D65 but shifts noticeably under TL84, the dye formula is metameric. This is grounds for rejection and reformulation.

Light booths (standardised multi-source light cabinets) are standard equipment in export garment factories. Brands can request that factories include a metamerism assessment in their lab dip submission.

**Metamerism specification language for tech packs**: "Colour to match standard (TCX XX-XXXX) under D65 with no significant metamerism under TL84."

### 5.5 Bulk Colour Approval and Quality Control

When bulk production is complete, a fabric sample from the bulk roll is measured against the **approved lab dip** (not the original Pantone swatch — the approved lab dip is the production standard). Factories use a **spectrophotometer** to measure the Delta E difference between the bulk and the approved dip.

If the Delta E exceeds the agreed tolerance, the factory must re-dye or the brand may reject the goods. This is why the lab dip approval stage is so consequential — once a lab dip is approved, it becomes the legal colour standard for that production run.

## 6. Practical Colour Naming for Non-Designers

### 6.1 The Three Dimensions of Any Colour

Every colour can be described using three independent dimensions. Understanding these three axes allows non-designers to navigate colour confidently and communicate precisely:

**1. Temperature (Warm vs. Cool)**
- **Warm**: The colour has undertones of red, orange, or yellow. Feels energetic, organic, inviting. Examples: terracotta, camel, peach, warm white (cream), warm grey (greige).
- **Cool**: The colour has undertones of blue, green, or purple. Feels calm, clean, modern. Examples: slate, powder blue, cool grey, icy white, sage.
- **Neutral**: Neither clearly warm nor cool; sits between. Examples: true mid-grey, pure white.

**2. Lightness (Light vs. Dark)**
- **Light / Pale**: High proportion of white in the colour — pastels, soft tones, off-whites.
- **Mid-tone**: Neither light nor dark — the colour is fully itself without being washed out or very deep.
- **Dark / Deep**: High proportion of black in the colour — navies, forest greens, charcoals, deep wines.

**3. Saturation (Saturated vs. Muted)**
- **Saturated / Vivid / Bright**: The colour is intense and full — no grey mixed in. Think cobalt blue, lipstick red, sunflower yellow.
- **Muted / Desaturated / Dusty**: The colour has grey mixed in — it is softer, quieter, more complex. Think dusty rose, sage green, slate blue, weathered brick.
- Think of saturation as "how close the colour is to grey" — fully saturated is far from grey; muted is moving towards grey.

These three dimensions can describe any colour without industry jargon: "a light, cool, muted blue" describes a powder blue with grey undertones; "a dark, warm, saturated red" describes a deep burgundy-adjacent crimson.

### 6.2 Consumer-Friendly Colour Vocabulary and What It Maps To

### 6.3 Bridging Consumer Names to Pantone References

The path from a founder's colour idea to a Pantone TCX code follows this sequence:

1. **Start with the consumer word**: "I want a dusty mauve."
2. **Describe using the three dimensions**: Light-to-mid, cool (purple undertone), muted (grey mixed in).
3. **Locate the Pantone FHI region**: Using either the physical Cotton Passport (organised by colour family and lightness) or Pantone's digital tools, navigate to the appropriate zone of the muted red-purple-grey section, lightness level 14–17.
4. **Narrow by visual evaluation**: Review swatches in that zone against the brand's reference image, moodboard, or fabric sample.
5. **Confirm the exact TCX code**: The selected swatch's code becomes the spec.

**Digital tools available**:
- **Pantone Connect** (pantone.com) — allows digital search of the FHI library by colour name, number, or by uploading a reference image. Outputs TCX codes.
- **Adobe CC integration** — Pantone FHI colours are available as a swatch library within Illustrator and Photoshop, allowing tech pack colour pages to be built digitally.
- **Hex-to-Pantone converters** — exist as browser tools, but treat these as starting-point approximations, not precise matches. Always verify against the physical swatch before issuing a spec to a factory.

### 6.4 What the App Should Help Founders Do

For the style brief builder, the colour selection flow should:

1. **Present archetypes first** — let founders self-identify their palette direction (neutral, earth, bright, pastel, quiet luxury, dark/moody, coastal) before showing specific colours.
2. **Use the three-dimension vocabulary** as a filtering layer — warm/cool, light/dark, saturated/muted — rather than asking founders to know Pantone codes.
3. **Surface Pantone TCX codes behind the scenes** — the founder selects a colour visually; the app maps it to the correct TCX reference for the tech pack.
4. **Present consumer-friendly names alongside codes** — "Warm Terracotta (18-1244 TCX)" is more useful than either alone.
5. **Note fabric compatibility** — flag when a selected colour is challenging on a non-cotton substrate so founders understand the manufacturing implication before they reach the factory.
6. **Distinguish core palette from seasonal accents** — prompt founders to separate their permanent brand colours from season-specific additions.

## Appendix: Key Terminology Reference

| Term | Definition |
|---|---|
| **TCX** | Textile Cotton eXtended — Pantone FHI colour dyed on cotton; primary apparel reference |
| **TPG** | Textile Paper Guide — Pantone FHI colour on paper; used for hard goods and accessories |
| **PMS** | Pantone Matching System — print/graphic design system; not for textile use |
| **Lab dip** | Small fabric sample dyed to match a colour standard; first physical test before bulk production |
| **Strike-off** | Print sample on production fabric; equivalent of lab dip for printed fabrics |
| **Delta E (ΔE)** | Numerical measure of colour difference; ΔE <1.0 imperceptible; ΔE 1.0–2.0 acceptable in production |
| **Metamerism** | Two colours that match under one light source but differ under another |
| **Colour fastness** | Resistance of dyed colour to fading or bleeding under washing, light, rubbing, etc. |
| **Reactive dye** | Dye class for cellulosic fibres (cotton, linen, viscose); forms covalent bond; high fastness |
| **Disperse dye** | Dye class for synthetic fibres (polyester, nylon); requires high heat and pressure |
| **Acid dye** | Dye class for protein fibres (wool, silk) and nylon; applied in acidic bath |
| **Vat dye** | Dye class for cotton; highest fastness; includes indigo/denim |
| **Coloro** | Colour system developed alongside WGSN; uses 5-digit codes; integrates with Pantone |
| **WGSN** | World Global Style Network; leading trend forecasting platform for fashion |
| **S/S** | Spring/Summer season |
| **A/W** | Autumn/Winter season |
| **Tech pack** | Technical package — the document specifying every detail of a garment for factory production |
| **D65** | Standardised daylight (6500K); primary light source for colour evaluation |
| **TL84** | Retail fluorescent light; used as secondary light source to check metamerism |
| **AATCC** | American Association of Textile Chemists and Colorists; US testing standard body |
| **ISO 105** | International standard series for colour fastness testing |
